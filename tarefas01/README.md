# 📇 Lista de Exercícios 1 - Estudando as estruturas básicas

Esta pasta do repositório foi criada para a entrega da "LISTA DE TAREFAS 01 - T1/2026", desenvolvido em JavaScript com Node.js, onde as tarefas estão nomeadas/numeradas de `atividade01.js` até `atividade10.js`.

## 📋 Pré-requisitos

Antes de começar, você precisa ter o [Node.js](https://nodejs.org/) instalado na sua máquina.

## ⚙️ Instalação

1. Clone somente esta pasta do repositório. Caso tenha optado clonar todo o repositório *maisPraTI-codifica*, siga para o *passo 2* da instalação.
   
    ```bash
    git clone -n https://github.com/moralesmarcel/maisPraTI-codifica.git
    cd maisPraTI-codifica
    git checkout HEAD tarefas01
    ```

2. Entre no diretório pertencente a essa _LISTA DE TAREFAS 01 - T1/2026_:

    ```bash
    cd tarefas01
    ```
    
3. Instale a única dependência necessária:
   
    ```bash
    npm install prompt-sync
    ```

🚨 Este projeto utiliza apenas a biblioteca _'prompt-sync'_, responsável por permitir a entrada de dados pelo terminal

---

## 🛠️ Como executar os arquivos da _"LISTA DE TAREFAS 01 - T1/2026"_

Os arquivos estão localizados na pasta do projeto (tarefas01), nomeados de `atividade01.js` até `atividade10.js`.

1. Para executar qualquer Atividade, use o comando:
 
    ```bash
    node atividade01.js
    ```

🚨 Substitua o `atividade01.js` pelo nome do exercício que deseja testar, como por exemplo `atividade05.js`, `atividade08.js`, etc.
